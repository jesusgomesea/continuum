# @continuum/agente

**O programa da loja.**

- Junta os caixas da loja e o estoque da loja
- Sincroniza com o ERP do cliente (sobe vendas, desce cadastro e preços)
- Envia o sinal de vida para o monitoramento

No formato MEI, roda embutido no PDV.
